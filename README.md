## 🚀 About Me

👋 Hi there! I'm a Senior Software Architect with a passion for technology, both professionally and personally. In my day-to-day work in the banking sector, I primarily work with Java and Python to develop robust and scalable software solutions.

Beyond my professional life, I'm deeply interested in microcontrollers, particularly the ESP32. My latest project, a weather station, is a great example of how I love turning tech into exciting and useful applications.

I highly value connecting and networking with other tech enthusiasts, especially in the Vienna area. If you share an interest in technology—whether professionally or as a hobby—I'd love to hear from you!

🐱 When I'm not working, I enjoy spending time with my two cats, who provide the perfect balance to my programming endeavors.
